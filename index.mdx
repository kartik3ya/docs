One REST call per image: a verdict, which detector fired, both detector scores and the face box.

**Base URL:** `https://api.checkobot.ai`

## Your first call

<Steps>
  <Step title="Get an API key">
    API keys come with the API plans. Create one in your [dashboard](https://checkobot.ai/dashboard/keys) and copy it when it's shown: we store only a hash of each key.
  </Step>
  <Step title="Send an image">
    <CodeGroup>

    ```bash curl
    curl https://api.checkobot.ai/v1/check \
      -H "Authorization: Bearer $CHECKOBOT_API_KEY" \
      -F "file=@photo.jpg"
    ```

    ```python Python
    import os, requests

    r = requests.post(
        "https://api.checkobot.ai/v1/check",
        headers={"Authorization": f"Bearer {os.environ['CHECKOBOT_API_KEY']}"},
        files={"file": open("photo.jpg", "rb")},
        timeout=60,
    )
    r.raise_for_status()
    result = r.json()
    print(result["band"], result["fired"], result["reason"])
    ```

    ```javascript JavaScript
    import { readFile } from "node:fs/promises";

    const form = new FormData();
    form.append("file", new Blob([await readFile("photo.jpg")]), "photo.jpg");

    const r = await fetch("https://api.checkobot.ai/v1/check", {
      method: "POST",
      headers: { Authorization: `Bearer ${process.env.CHECKOBOT_API_KEY}` },
      body: form,
    });
    const result = await r.json();
    console.log(result.band, result.fired, result.reason);
    ```

    </CodeGroup>
  </Step>
  <Step title="Read the verdict">
    `band` is `ai` or `no_ai` (shown as "No AI detected"), `fired` says which detector crossed its threshold, and `reason` is one line you can show to people. See [Check an image](/check) for every field.
  </Step>
</Steps>
